## Uruchamianie
1. Zainstaluj na komputerze Pythona w wersji minimum 3.10
2. Pobierz projekt jako paczkę ZIP z repozytorium GitHub i rozpakuj ją na swoim komputerze.
3. Otwórz terminal bezpośrednio w rozpakowanym folderze i wykonaj polecenie startowe, aby włączyć program:
   ```bash
   python main.py
   ```
